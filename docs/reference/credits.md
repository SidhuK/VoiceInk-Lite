# Credits

VoiceInk Lite is a modified version of [VoiceInk](https://github.com/Beingpax/VoiceInk) by Prakash Joshi. Almost all of the app is his work.

## Transcription

- [whisper.cpp](https://github.com/ggerganov/whisper.cpp) runs OpenAI's Whisper models on your Mac.
- [FluidAudio](https://github.com/FluidInference/FluidAudio) runs the Parakeet models.
- [TranscribeCpp for Swift](https://github.com/Beingpax/Transcribe-cpp-swift) packages [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp) for the local GGUF models.
- [SenseVoice Small](https://huggingface.co/FunAudioLLM/SenseVoiceSmall) by FunAudioLLM / Alibaba is a multilingual model, available under the [FunASR Model Open Source License Agreement](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE).

## Other libraries

- [LLMkit](https://github.com/Beingpax/LLMkit) talks to the AI providers used for enhancement.
- [MLX Swift LM](https://github.com/ml-explore/mlx-swift-lm), [swift-transformers](https://github.com/huggingface/swift-transformers), and [swift-huggingface](https://github.com/huggingface/swift-huggingface) run language models on your Mac.
- [MarkdownUI](https://github.com/gonzalezreal/swift-markdown-ui) renders Markdown.
- [MediaRemoteAdapter](https://github.com/Beingpax/mediaremote-adapter) pauses and resumes media while you record.
- [SelectedTextKit](https://github.com/Beingpax/SelectedTextKit) reads selected text.
- [Zip](https://github.com/marmelroy/Zip) compresses backups.
- [Swift Atomics](https://github.com/apple/swift-atomics) provides atomic operations.
